# Writing Artifact Storage

This is where I keep my writing: drafts, finals, and practice work. Each
artifact should show not only the finished response, but also how the response
changed through planning, feedback, and revision.

Browse the sections in the sidebar:

- Paper 1: Rhetorical Analysis
- Paper 2: Comparative Literary Analysis
- HL Essay Drafts
- Oral Analysis Practice
- Non-Literary Text Study

When an assignment is still stored in Google Docs or Classroom, I link to the
authenticated source instead of pretending that a local copy exists. The
analysis on each page explains what the artifact is meant to demonstrate and
what I still need to add.
